# Python

This folder contains Python, NumPy, Pandas, Matplotlib and Seaborn practice — the core data-handling toolkit used throughout this repo.

## Contents

### 01_NUMPY.ipynb
- Array creation, indexing, slicing, reshaping
- Vectorized operations vs Python loops
- Broadcasting
- Aggregate functions (sum, mean, std, min/max)
- Random number generation

### 02_PANDAS.ipynb
- Series and DataFrame basics
- Reading/writing CSV data
- Indexing, filtering, and selection (`loc`, `iloc`)
- Handling missing values
- GroupBy, aggregation, and merging/joining DataFrames

### 03_MATPLOTLIB.ipynb
- Line, bar, scatter, and histogram plots
- Subplots and figure customization
- Labels, legends, titles, and styling

### 04_SEABORN.ipynb
- Statistical plots: distplot/histplot, boxplot, violinplot
- Categorical plots: countplot, barplot
- Correlation heatmaps
- Pairplots for multivariate relationships
